## Висновки щодо ефективності алгоритмів пошуку підрядка

### 1. Для Статті 1

- **Найшвидшим в обох випадках (реальний та вигаданий підрядок) виявився алгоритм Боєра-Мура:**
  - для реального підрядка — **0.02572 с**
  - для вигаданого підрядка — **0.03096 с**

  Це пояснюється тим, що алгоритм Боєра-Мура робить великі “стрибки” завдяки таблиці зміщення.

- **КМП та Рабін-Карп значно повільніші для цього тексту:**
  - КМП для реального — **0.23754 с**, для вигаданого — **0.19720 с**
  - Рабін-Карп для реального — **0.30633 с**, для вигаданого — **0.34470 с**

- **Висновок по статті 1:**  
  Для великих текстів з нерівномірним розподілом символів, де мало повторюваних фрагментів, Боєр-Мур дає найкращу продуктивність.

---

### 2. Для Статті 2

- **Знову найшвидший — Боєр-Мур:**
  - для реального підрядка — **0.00283 с**
  - для вигаданого — **0.01309 с**

- **КМП та Рабін-Карп демонструють ще більшу різницю:**
  - КМП для реального — **0.03237 с**, для вигаданого — **0.29742 с**
  - Рабін-Карп для реального — **0.04163 с**, для вигаданого — **0.52919 с**

- Для невеликих або більш “рівномірних” за структурою текстів, перевага Боєра-Мура ще більш помітна.

---

### 3. Загальні висновки

- **Боєр-Мур стабільно швидший за КМП і Рабін-Карпа на обох текстах — як для існуючих, так і для неіснуючих підрядків.**
- **КМП значно поступається Боєру-Муру, але перевершує Рабіна-Карпа в обробці більш регулярних патернів.**

---

### Практичний висновок

- У загальному порівнянні **найефективнішим рішенням для пошуку підрядка у великих текстах у більшості реальних випадків є алгоритм Боєра-Мура.**
- Якщо текст має багато повторюваних підрядків або потрібно знаходити багато підрядків одночасно, інші алгоритми можуть знадобитися.
- Важливо тестувати різні варіанти для конкретного типу тексту й підрядків, оскільки ефективність сильно залежить від структури даних.
